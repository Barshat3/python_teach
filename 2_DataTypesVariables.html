Python Basics

What is a Variable?

In simple words, a variable is a container for storing data values.

Key Purposes:

  • Used to store data for later use in your code.
  • The stored data can be numbers, text, or complex values.
  • Allows your programs to be dynamic and reusable.

Syntax & Protocol

Defining & Naming Variables

The Assignment Syntax

# Syntax
variable_name = value

# Real World Example
name = "Alex"
Pro-Tip: The = sign in Python isn't "equal to" like in math. It is an assignment operator that pushes the right side value into the left side container.

Strict Rules for Naming

Valid Names
  • name
  • _age
  • favorite_color

Must start with a letter or underscore (_).

Invalid Names
  • 2name
  • my name
  • @age

Cannot start with a number, contain spaces, or special characters.

Data Architecture

Data Types in Python

Python dynamically infers the nature of data you save. Here are the 4 essential foundation types:

str

String

Text data enclosed inside quotes "" or ''.

name = "Alex"
int

Integer

Whole numbers stretching from negative to positive infinity.

age = 25
float

Float

Real fractional numbers containing decimal points.

height = 5.4
bool

Boolean

Binary state representation. Holds either True or False.

is_active = True
Output Generation

Displaying Variables

1. Basic Printing Syntax

Pass the variable name inside the print() function call natively.

name = "Alex"
print(name) # Output: Alex

2. Multi-argument Combinations

Separate plain text sentences and variable instances cleanly with commas.

name = "Alex"
age = 25
print("My name is", name, "and I am", age, "years old.")
Under the Hood Execution Engine
