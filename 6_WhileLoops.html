Control Flow Core

What is a Loop?

Loops allow you to execute a block of code multiple times without writing the exact same code repeatedly.

Real-World Analogy

Think of running laps around a track. Instead of stating "Run lap 1", "Run lap 2", you set a instruction: "While laps completed is less than 5, keep running."

Python provides two primary kinds of loops:

for loop
while loop
The Lazy Programmer Way

# Bad: Repetitive & hard to maintain

print("Hello World")
print("Hello World")
print("Hello World")
print("Hello World")
print("Hello World")
Transform to Loop

# Clean: Scale to 5 or 5,000 effortlessly

for i in range(5):
    print("Hello World")
Condition-Driven Execution

The While Loop

A while loop repeatedly executes a block of code as long as a specified condition evaluates to True.

Blueprint Syntax

while condition:
    # code block to execute
    # must change something inside condition!
Essential Warning

If the condition stays true forever, your loop will turn into an infinite loop, causing your program to crash or hang!

Concrete Execution Trace

i = 1
while i <= 5:
    print(i)
    i += 1  # Increment the counter

Loop Intervention Modifiers

Break & Continue Statements

Emergency Exit

break

Exits the active loop sequence immediately, ignoring any remaining lines inside the block or remaining conditional passes.

for i in range(1, 10):
    if i == 5:
        break # Abort everything!
    print(i)
# Outputs: 1, 2, 3, 4
Fast-Forward

continue

Skips the remaining code inside the current iteration block and directly jumps straight to the next loop evaluation step.

for i in range(1, 10):
    if i == 5:
        continue # Skip printing 5!
    print(i)
# Outputs: 1, 2, 3, 4, 6, 7, 8, 9
