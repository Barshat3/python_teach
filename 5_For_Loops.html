Python Programming Foundations

Control Flow: Understanding Loops

Imagine writing a script where you need to repeat an instruction 100 times. Copy-pasting code is exhausting and messy. Loops solve this by letting us run a block of code repeatedly with zero code duplication.

For Loops

Best utilized when you want to iterate over a precise, predefined sequence like a list, string, or fixed range.

While Loops

Used to loop purely based on a conditional state. It repeats continuously until the evaluation becomes False.

Core Mechanism

Anatomy of a For Loop

A for loop steps through each element inside a sequence (like a range of numbers) sequentially.

Abstract Syntax 
for variable in sequence:
    # block of code to run

Pro-Tip: The Range Function

range(start, stop) begins exactly at start, but halts right before reaching stop!

Live Application Structure 
# This loop triggers exactly 5 times (from 1 up to 5)
for i in range(1, 6):
    print("Hello, World!")
Advanced Flow Alteration

Loop Modifiers: Break & Continue

Sometimes we need to break out of a loop prematurely or bypass specific conditions mid-execution. Python offers two special operators to modify workflow.

break Statement

Terminates execution of the current loop completely and forces execution down to the subsequent block. 

for i in range(1, 10):
    if i == 5:
        break  # Stops completely at 5
    print(i)
continue Statement

Skips the remaining statements within the current running block and immediately returns to evaluate the next cycle state. 

for i in range(1, 10):
    if i == 5:
        continue # Skips printing 5
    print(i)
