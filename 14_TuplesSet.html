COLLECTION 01

What is a Tuple?

A tuple is an ordered, fixed collection of elements. Think of it as a historical blueprint record: once declared, it remains frozen in time.

Ordered: Preserves index placement sequence.
Immutable: You cannot modify, add, or append elements once generated.
Syntax: Declared using standard parentheses ( ) instead of brackets.
Analogy: Like coordinates on a static map. If a location is at (40.7128, -74.0060), altering any coordinate points somewhere else entirely!
tuple_definition.py 
# Syntax framework definition
tuple_name = (element1, element2, element3)

# Real-world practical declaration
colors = ("red", "green", "blue")

# Sequential indexing retrieval
print(colors[1])  # Output: green
Tuple Operations

Accessing & Immutability Constraints

Read-Only Safety

Accessing Tuple Elements

Tuple elements are explicitly mapped directly to fixed integer-based indices starting from 0. 

fruits = ("apple", "banana", "cherry")

# Fetch element at positional index index 1
print(fruits[1])  
# Output: banana

The Immutability Trap

Attempting to overwrite values inside an active tuple produces an explicit structural assignment error. 

fruits = ("apple", "banana", "cherry")

# Attempting mutation reassignment
fruits[1] = "kiwi" 

# ❌ CRASHES WITH EXPLICIT ERRORS:
# TypeError: 'tuple' object does not support item assignment
COLLECTION 02

What is a Set?

A set represents a high-efficiency mathematical container of unique elements completely stripped of ordering positions.

Unordered: Elements possess no designated numeric indexing positions.
No Duplicates Allowed: Every item within a set must be entirely distinct.
Syntax: Initialized using explicit curly brackets { }.
Key Use-Case: Instantly stripping duplication arrays from tracking matrices or performing mathematical union/intersection checks.
set_definition.py 
# Base architecture framework initialization
set_name = {element1, element2, element3}

# Practical instance creation
numbers = {1, 2, 3, 4}
print(numbers)  # Output: {1, 2, 3, 4}

# Notice: Order is non-guaranteed over runtime sequences!
Set Operations

Adding, Removing, & Uniqueness

Dynamic Mutability

Dynamic Manipulation APIs

While individual entries cannot be edited in-place, the set object container can be updated via explicit structural adjustments. 

fruits = {"apple", "banana", "cherry"}

fruits.add("orange")     # Inserts 'orange' smoothly
fruits.remove("banana")  # Strips away 'banana' target

print(fruits) 
# Output: {'apple', 'cherry', 'orange'}

Automatic Filtration Architecture

Duplicate element initializations are completely dropped by the runtime rendering engine automatically. 

# Initializing duplicates directly
numbers = {1, 2, 3, 3, 4}

print(numbers) 
# Output automatically purges replication:
# {1, 2, 3, 4}
