What is a Dictionary?

A dictionary is an unordered (or order-preserving from Python 3.7+), mutable collection of key-value pairs. Each key must be completely unique and maps uniquely to a specific target value.

Generic Mapping Blueprint dictionary_name = {key1: value1, key2: value2}
Analogy Note Think of a real-world language dictionary: You look up a unique Word (Key) to find its matching Definition (Value)!
Structural Syntax Breakdown 
# Declaring a dictionary object
student = {
    "name": "Alice",  # String key mapping to String value
    "age": 12,        # String key mapping to Integer value
    "grade": "A"      # String key mapping to String value
}

Accessing & Modifying Target Elements

Retrieval Architecture

We use the key encased in matching square brackets ([key]) to rapidly fetch associated values. 

student = {"name": "Alice", "age": 12, "grade": "A"}

# Fetch value mapped under key "name"
print(student["name"]) 

# Terminal Output:
# Alice

Mutation Protocols

We shift or overwrite existing configurations by pinpointing the specific target key and assigning it a new value. 

student = {"name": "Alice", "age": 12, "grade": "A"}

student["age"] = 13 # Modify key "age" securely

print(student)
# Terminal Output:
# {'name': 'Alice', 'age': 13, 'grade': 'A'}

Dynamic State Changes: Add & Delete

Element Inclusion Architecture

If an assigned key does not exist yet inside your dictionary target, Python creates it instantly. 

student["school"] = "XYZ High School"
print(student)
# {'name': 'Alice', 'age': 13, 'grade': 'A', 'school': 'XYZ High School'}

Structural Removal Protocol

The del command completely destroys the mapping key along with its paired values. 

del student["grade"]
print(student)
# {'name': 'Alice', 'age': 13, 'school': 'XYZ High School'}
