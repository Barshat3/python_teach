What are Nested Loops?

A nested loop is simply a loop inside another loop. They are incredibly powerful tools used extensively for exploring multi-dimensional spaces, generating graphical grids, building data tables, or printing complex textual patterns.

Core Roles:
  • Outer Loop: Controls rows, high-level structural phases, or slow cycles.
  • Inner Loop: Controls columns, individual step elements, or fast cycles.
Golden Rule For every single completion step of the outer loop, the inner loop executes completely from start to finish!

Syntax Template

for i in range(outer_limit):     # Outer loop (Rows)
    for j in range(inner_limit): # Inner loop (Columns)
        # Code block executes (outer_limit * inner_limit) times
        pass

Tracing Loop Execution

Let's observe exactly how state evolves during nesting execution. Notice how the inner state cycles completely through while the outer index remains completely fixed. 

for i in range(3): # Outer loop
    for j in range(2): # Inner loop
        print(f"Outer: {i}, Inner: {j}")

Total Cycles Calculations

Outer steps = 3 ($i \in \{0, 1, 2\}$)
Inner steps = 2 ($j \in \{0, 1\}$)
Total print operations executed = $3 \times 2 = 6$ total lines.
